# Etix

Editor de etiquetas e documentos para Windows, com dados variáveis, impressão em lote e impressão
direta nas impressoras Zebra. Desenvolvido pela **RINT - Integração e Soluções**.

Este repositório tem só as versões publicadas do Etix (o código não é público).

## Descarregar

- Última versão: [Etix.exe](https://github.com/rjvc/etix-releases/releases/latest/download/Etix.exe)
- Todas as versões e as novidades de cada uma: [Releases](https://github.com/rjvc/etix-releases/releases)

## Instalar

1. Descarregue o `Etix.exe` e abra-o. Corre logo, sem instalar e sem administrador.
2. Para o deixar no menu Iniciar e abrir os `.tix` com duplo clique, carregue em
   "Instalar o Etix neste computador", na tab de início. Fica na sua conta
   (`%AppData%\Etix`), sem administrador.

Precisa de Windows 10 ou 11 (o .NET Framework 4.8 e o WebView2 já vêm com o Windows).

## Atualizações

O Etix procura uma versão nova aqui pouco depois de abrir e de 4 em 4 horas. Quando há, descarrega-a,
confirma que foi assinada pela RINT e mostra "Reiniciar para atualizar". Uma versão sem a assinatura
certa é recusada.
